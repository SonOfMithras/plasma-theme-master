# Zapfast

Themes [Zapfast](https://github.com/crmne/zapfast) with the active PTM palette.

## Setup

1. Launch Zapfast once, then enable this template in PTM.
2. In Zapfast, select `ptm.json` in the theme settings.

PTM regenerates the theme when the palette changes. The post-hook attempts to reload Zapfast's themes; if Zapfast is closed, the generated theme will be available the next time it starts.

## Output path

- Native: `$XDG_CONFIG_HOME/zapfast/themes/ptm.json`
