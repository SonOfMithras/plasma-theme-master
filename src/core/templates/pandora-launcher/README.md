# Pandora Launcher

Generates a **PTM** theme for Pandora Launcher.

Install Pandora Launcher and enable **Pandora Launcher** in **PTM Settings -> Templates**. The theme is written to `$XDG_DATA_HOME/PandoraLauncher/themes/ptm.json`. Select **PTM** in the launcher's theme settings manually.

Back up any existing file at that path: generation replaces it. No hook changes launcher settings or triggers a reload.
