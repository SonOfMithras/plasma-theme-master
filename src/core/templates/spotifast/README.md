# Spotifast

Themes [Spotifast](https://github.com/crmne/spotifast) with the active
PTM palette. Requires Spotifast 0.9.1 or newer.

## Setup

1. Launch Spotifast once, then enable this template in PTM.
2. In Spotifast, open **Settings → Appearance → Theme** and select
   `ptm.json`.

PTM reloads a running Spotifast instance after palette changes. If
Spotifast is closed, the updated palette is loaded on its next start.

Disable **Accent from album art** in Spotifast's Appearance settings if you
want all surfaces to retain the PTM colors.

## Output paths

- Native: `$XDG_CONFIG_HOME/spotifast/themes/ptm.json`
- Flatpak: `~/.var/app/rocks.spotifast.Spotifast/config/spotifast/themes/ptm.json`
