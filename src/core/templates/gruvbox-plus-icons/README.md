# Gruvbox Plus Icons — PTM Community Template

Recolors the folder icons of [Gruvbox Plus](https://github.com/SylEleuth/gruvbox-plus-icon-pack) with the PTM theme's primary color.

Gruvbox Plus installed via your package manager, or placed in your icons directory (`~/.local/share/icons` or `~/.icons`), is currently required.

> **Note on System-Wide Installations:** If Gruvbox Plus is only installed system-wide, the script will copy it once to `~/.local/share/icons`. Please note that this local copy will not automatically receive later package updates from your system manager.
