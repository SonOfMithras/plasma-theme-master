# PTM SpeedCrunch Template

A [PTM](https://github.com/ptm-dev/ptm-shell) user template that generates a [SpeedCrunch](https://github.com/heldercorreia/speedcrunch) theme from your current PTM colors.

## Setup

In SpeedCrunch, open the color scheme settings and select PTM theme: 
   ```
   Settings -> Appearance -> Theme -> Import Theme -> ~/.local/share/SpeedCrunch/color-schemes/PTM.json.
   ```
