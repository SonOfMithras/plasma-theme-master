# OpenCode

Generates an OpenCode theme from the PTM palette, including UI, syntax, Markdown and diff colors.

Install OpenCode and enable **Opencode** in **PTM Settings -> Templates**. The output is `$XDG_CONFIG_HOME/opencode/themes/matugen.json`. Select the custom **matugen** theme in OpenCode; this template does not change your selected theme.

The generated file is replaced on palette updates, so back up any existing customizations there. No hook or reload command is supplied.
